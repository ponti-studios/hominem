Failure states

  • Offline

    Banner drops from the top. Send and verify stop before the spinner starts, the field shakes, and the mascot says it will wait. Coming back online clears the error and re-submits a full code on its own. Haptic: error.

  • Send fails

    Server said no. The email stays put with a message under it, so one tap tries again. Fires once, then the next send works.

  • Code expired

    Pebbles turn coral, the message says to ask for a new code, and Resend unlocks right away instead of waiting out the 30s timer. Fires once.

  • Lockout

    Enter 000000 three times. The second miss warns it is the last try. The third dims the pebbles, makes the field read-only and counts down 30s, then clears and refocuses. Haptic: warning. Resend stays off until it unlocks.

  • Paste

    Paste 123 456 or 123-456 into the code field. Spaces and dashes are dropped and it still auto-submits once. A fresh code (Resend) resets the tries.

Beats

  1. 0 ms
    Native splash

    Static image from expo-splash-screen: the mascot alone, centred, on the app ground. Same ground in dark mode.

  2. 500 ms
    In-app splash takes over

    Identical frame, so there is no visible swap. Mascot hellos (700ms spring) and the wordmark types in letter by letter.

    hides native splash only after auth + cache restore
  3. 1,300 ms
    Mascot travels up

    One transform (translate + scale) over 900ms. The email field is the same ink pill and violet send circle as the capture bar, so the first thing you touch already looks like the app. Omiro greets you in a speech bubble and nods on every keystroke.

  4. on send
    Email slides to code

    Both steps share one slot, so the screen never changes route. The send circle pulses when the address is valid, then shows dots. The pill fades and six ink pebbles are dealt out from where the send circle was; the mascot leans in. Auto-submits on the sixth digit, pebbles wave while checking.

    haptic: light on send, error on mismatch
  5. on verify
    Success

    Pebbles turn lime left to right, the mascot straightens and hops, bubble says welcome. A wrong code turns them coral and shakes the row.

    haptic: success
  6. +900 ms
    Handoff to the inbox

    Mascot lifts away, tiles rise 90ms apart, composer bar settles last. Returning users skip login and go straight here after a 600ms hold.
