Plain is today. Colors tints markdown without changing any character width, so the cursor and selection behave exactly as they do now. Rich also changes weight and size (headings grow, bold is bold); it looks best but is the riskiest to build in a React Native text input, so I would want your call before going there.

What changed

  • Bar: five actions you reach for most (Aa, checklist, bullet list, indent, outdent) plus dismiss, in the same ink pill as the capture bar. Every tap target is 44pt. Nothing scrolls sideways.
  • Aa panel: everything else, labelled and grouped. It shows what the cursor is already in (bold, a heading, a list) so a tap on the same button removes it. A new command is one more tile; the bar never gets longer.
  • Text: title 30 / bold, body 17 on a 28 line. The rendered preview already used 17/28, so editing and previewing now match.
  • Why a floating panel: iOS does not let an app swap the keyboard for its own panel, so the panel opens above the bar and the keyboard and cursor stay put.
